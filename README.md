# YeahPromos Main Page

A high-fidelity, responsive homepage redesign inspired by the spatial editorial system of the Optimus reference site and rebuilt around YeahPromos' own content, assets, colors, and audiences.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is a static Vite site and can be deployed to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
